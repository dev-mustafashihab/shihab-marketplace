# UX RULES — القواعد الملزمة (مراجعة كل PR وفقها)

## القواعد العشر (من المؤسس — ملزمة)
1. أهم Action واضح في كل شاشة.
2. لا ازدحام — مساحة تنفس 16/24 على الأقل.
3. CTA رئيسي واحد لكل سياق.
4. Progressive Disclosure — التفاصيل عند الطلب.
5. Forms طويلة = مقسمة خطوات مع حفظ.
6. مدخلات الحجز محفوظة بين الخطوات (ولو خرج التطبيق).
7. السعر النهائي دائماً ظاهر قبل الدفع (بلا رسوم مفاجئة).
8. التوفر يُعرض قبل أي خطوة دفع.
9. لا Animation للتزيين — فقط بهدف (تأكيد/توجيه/انتظار).
10. UX قبل Visual Effects — لا gradients/glass/ظلال ثقيلة.

## قواعد المحتوى والرسائل
- ممنوع للمستخدم النهائي: Exception, 500, NullPointerException, AxiosError, «فشل الاتصال بالسوكيت»...
- النموذج: «حدث خطأ أثناء تأكيد الحجز. أعد المحاولة أو تواصل معنا.»
- الأزرار صيغة فعل: «احجز الآن»، «أكمل الطلب»، «أضف عنواناً».
- Empty states بصيغة: ماذا نعرض + لماذا + ماذا يفعل المستخدم الآن.

## قواعد RTL والعربية
- `Directionality` من اللغة، لا محاذاة يدوية؛ أيقونات الاتجاه (chevron/back) تنعكس.
- الأرقام في الأسعار/التواريخ: غربية افتراضياً (وضوح)، مع token عرض موحد.
- الاختبار دائماً بنص عربي طويل حقيقي (مثال: «صالة قصر الأمل للاحتفالات الكبرى»).

## قواعد الأداء والإدراك
- أول معنى بصري ≤ 1s (Skeleton فوراً)؛ الصور بعرض الشبكة (no full-res).
- زر الدفع يمنع التكرار دائماً (Idempotency خلفية).
- الكاش للقراءة يبقى عند فشل refresh مع بانر غير معيق.

## UI Quality Gate (لا تُغلق مهمة شاشة دون كل البنود)
```
[ ] RTL سليم على كل الشاشات المتأثرة
[ ] Arabic typography (line-height، ellipsis، أرقام)
[ ] Loading state (Skeleton حيث يليق)
[ ] Empty state بفعل تالٍ
[ ] Error state بشرية + retry
[ ] Success state واضح (بعد تأكيد/حفظ)
[ ] Responsive (صغير/كبير/تابلت) بلا overflow
[ ] لا أبعاد صلبة مكسورة (باستخدام flex/expanded)
[ ] مكونات من core/widgets فقط
[ ] Tokens فقط (لا hex/spacing يدوي)
[ ] حالات API الثلاث مغطاة
[ ] Navigation مُختبر ذهاباً وعودة (لا فقدان حالة)
[ ] Touch targets ≥48dp وتباين 4.5:1
[ ] Semantic labels لعناصر الحالة
```

## أسئلة ما قبل أي شاشة (من المؤسس — تُجاب في PR وصف)
من يستخدمها؟ ما الهدف؟ ما الفعل الرئيسي؟ ما الأساسي؟ ما يمكن حذفه؟ ماذا يظهر أثناء التحميل/الفراغ/الخطأ/بعد النجاح؟
